# Hărți de relief (normal maps)

Texturi repetabile (512×512, WebP) din pachetul npm [`@pmndrs/assets`](https://github.com/pmndrs/assets)
(colecția `normals`, licență **CC0** — domeniu public, se pot folosi liber, fără atribuire obligatorie).

| Fișier       | Original  | Folosit pe                          |
|--------------|-----------|-------------------------------------|
| `snow.webp`  | 0014      | teren (zăpadă), troiene             |
| `stone.webp` | 0026      | pietre, mina, fundațiile turnurilor |
| `wood.webp`  | 0004      | scânduri, pari, case                |
| `bark.webp`  | 0011      | brazi (ace, scoarță)                |
| `metal.webp` | 0001      | fier, rugină                        |
| `cloth.webp` | 0028      | haine, zdrențe, blană               |
| `skin.webp`  | 0018      | piele (eroi, zombi), os             |
