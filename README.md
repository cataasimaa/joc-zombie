# Iarna Morților

Survival tower defense co-op 3D, cu temă de iarnă, pentru mobil. Babylon.js + TypeScript + Vite.

```bash
npm install
npm run dev
```

Deschide adresa afișată (merge și de pe telefon, în aceeași rețea Wi-Fi).
Controale: WASD / săgeți sau joystick-ul din stânga-jos, **B** / 🔨 pentru construcție,
**Enter** / „Pornește acum” ca să pornești valul imediat.

Designul complet și arhitectura: vezi [CLAUDE.md](CLAUDE.md).
