# Iarna Morților

Survival tower defense co-op 3D, cu temă de iarnă, pentru mobil. Babylon.js + TypeScript + Vite.

```bash
npm install
npm run dev
```

Deschide adresa afișată (merge și de pe telefon, în aceeași rețea Wi-Fi).
Începi din meniu: numele tău, dificultatea (Easy → Nightmare), sunet/muzică, apoi alegi eroul.
Controale: WASD / săgeți sau joystick-ul din stânga-jos pentru mers; **click ținut** (spre cursor) sau
degetul ținut pe ecran pentru tras; butonul ✛ (ții apăsat = ochire automată, tragi cu degetul = ochești tu);
**Space** trage; **R** reîncarcă; **B** / 🔨 construcție (**1/2/3** turn / zid / mină, **R** rotește,
**Enter** pune; atinge un turn ca să-i faci upgrade sau să-l transformi); **C** / 🎲 magazin;
**Esc** / ☰ pauză; **Enter** / „Începe noaptea” ca să vină noaptea imediat.

Designul complet și arhitectura: vezi [CLAUDE.md](CLAUDE.md).
