# Iarna Morților

Survival tower defense co-op 3D, cu temă de iarnă, pentru mobil. Babylon.js + TypeScript + Vite.

```bash
npm install
npm run dev
```

Deschide adresa afișată (merge și de pe telefon, în aceeași rețea Wi-Fi).
Începi din meniu: numele tău, modul (**Apără mina** sau **Supraviețuire**), dificultatea (Easy → Nightmare),
sunet/muzică și 🏆 clasamentul; apoi alegi eroul.
Controale: WASD / săgeți sau joystick-ul din stânga-jos pentru mers; **click ținut** (spre cursor) sau
degetul ținut pe ecran pentru tras (glonțul se oprește unde ai apăsat); butonul de tras (ții apăsat = ochire
automată, tragi cu degetul = ochești tu); **Space** trage; **R** reîncarcă (gloanțele nu sunt nelimitate);
**B** / ciocanul = construcții noi (**1/2/3/4** turn / zid / mină / foc); atinge orice construcție de-a ta ca
s-o modifici; **E** / **F** mănânci / pui carne pe foc (sau bara de jos); **C** / 🎲 magazin;
**Esc** / ☰ pauză; **Enter** / „Începe noaptea”.

Designul complet și arhitectura: vezi [CLAUDE.md](CLAUDE.md).
