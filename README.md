# Iarna Morților

Survival tower defense co-op 3D, cu temă de iarnă, pentru mobil. Babylon.js + TypeScript + Vite.

```bash
npm install
npm run dev
```

Deschide adresa afișată (merge și de pe telefon, în aceeași rețea Wi-Fi).
Controale: WASD / săgeți sau joystick-ul din stânga-jos pentru mers; **mouse + click ținut** sau butonul ✛
(ții apăsat = ochire automată, tragi cu degetul = ochești tu) pentru tras; **Space** trage automat;
**R** reîncarcă; **B** / 🔨 construcție (**1/2/3** turn / zid / mină, **R** rotește, **Enter** pune);
**C** / 🎲 magazin; **Enter** / „Începe noaptea” ca să vină noaptea imediat.

Designul complet și arhitectura: vezi [CLAUDE.md](CLAUDE.md).
